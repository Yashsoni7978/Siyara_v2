## 3. Redirect Strategy & Legacy Route Plan

The following redirects should be maintained or adjusted in `next.config.js`:

```javascript
async redirects() {
  return [
    // 1. Maintain Legacy Portfolio Unification
    { source: '/portfolio', destination: '/work', permanent: true },
    { source: '/our-work', destination: '/work', permanent: true },

    // 2. CRITICAL FIX: REMOVE /industries/hospitality redirect
    // (This line must be removed so app/industries/hospitality/page.jsx is reachable)
    // - DELETE: { source: '/industries/hospitality', destination: '/services', permanent: true }

    // 3. REMOVE /industries redirect once /industries index page is built
    // (Once app/industries/page.jsx exists, this redirect will be disabled)
    // - TEMPORARY: { source: '/industries', destination: '/services', permanent: true }

    // 4. Retired Category Redirects
    { source: '/industries/fitness', destination: '/industries', permanent: true },

    // 5. Normalized Service Aliases
    { source: '/services/app-development', destination: '/services/mobile-app-development', permanent: true },
    { source: '/services/ai-agents', destination: '/services/ai-automation', permanent: true },

    // 6. Blog to Insights Canonical Unification
    { source: '/blog', destination: '/insights', permanent: true },
    { source: '/blog/:slug*', destination: '/insights/:slug*', permanent: true },
  ];
}
```
